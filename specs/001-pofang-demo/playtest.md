# T15 陌生用户 3 分钟试玩脚本 + 观察表

目标：找 1–2 位没看过项目的同学（最好非本项目队友），真机试玩 3 分钟，掐表 + 录屏，按动线卡点修问题。
执行人：用户/队友（AI 无法代替真人观察）。

## 准备

- 链接：https://pofang-game-hf2x9frsjfn.qoder.zone （手机浏览器直接打开即可，无需安装）
- 录屏：手机自带录屏或电脑 OBS；另开秒表记总时长
- 规则：**不讲解玩法**。只说「打开这个链接，随便玩 3 分钟」，观察对方能否自己看懂
- 试玩者画像记录：手机/电脑、平时玩不玩游戏、是否住宿舍

## 3 分钟动线与观察表

| # | 时间点 | 观察点 | 期望行为 | 实际（填） | 卡点？ |
|---|---|---|---|---|---|
| 1 | 0:00–0:15 | 首屏理解 | 10s 内说出「要说服/攻击这个角色」之类目标理解 | | |
| 2 | 0:15–0:40 | 第一招 | 自己点弹药或输入框出招，不问「怎么玩」 | | |
| 3 | 0:40–1:10 | 反馈理解 | 注意到嘴硬值掉血 / 伤害飘字 / 裁判评语 | | |
| 4 | 1:10–2:00 | 策略尝试 | 换弹药或自己造句；发现复读伤害低更佳 | | |
| 5 | 2:00–2:40 | 结算反应 | 破防或失败后看战绩卡；有无保存/分享口头意愿 | | |
| 6 | 2:40–3:00 | 复玩意愿 | 主动点「再来一局」或口头说想再试 | | |
| 7 | 可选 | 彩蛋 | 提示「试试开挂」后点💉，看反嘲讽反应 | | |

计时记录：首招耗时 ____ s；整局耗时 ____ s；是否 90s 内破防 ____

## 玩后三问（原话记录）

1. 哪个瞬间最好笑 / 最爽？
2. 哪一步不知道干什么 / 等得烦？
3. 会不会把战绩卡发群里？为什么？

## 修问题判定

- 任一观察点 ≥1 人卡住（问「怎么玩」/ 停手 >10s）→ 记为卡点，回 specs 修 UI 文案或引导
- 「等得烦」集中出现 → 复核演员/裁判预算与流式首字延迟（当前 10s/12s，首字通常 2–4s）
- 无人卡点且 ≥1 人主动复玩 → T15 通过
