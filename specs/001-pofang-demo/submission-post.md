## 标题

【LifeHack】破防吧！同学 —— 和 AI 嘴硬室友对线，8 回合内说服他去洗碗

## 一、自我介绍

我们是【学校】的两人学生队伍【队名】：【成员 A 昵称/分工】、【成员 B 昵称/分工】。
平时爱做游戏化小产品，这次想用 AI 把「宿舍嘴硬日常」做成一局 3 分钟的语言对战。

## 二、一句话作品

打开链接即玩：用讲道理 / 阴阳怪气 / 胡搅蛮缠攻击 AI 嘴硬室友「阿伟」，
8 回合内打空 100 点嘴硬值即破防，生成可保存分享的战绩卡。
三位校园 Boss 可切换：洗碗拖延室友 / 装懒卷王 / 画饼主席，破防瞬间有慢镜头处刑演出。
在线体验：https://pofang-game-hf2x9frsjfn.qoder.zone （手机可玩，无需注册）
代码开源：https://github.com/192aaa/pofang-game

## 三、为什么做

宿舍真实痛点：碗泡三天「泡软了好洗」的嘴硬室友，谁都说不动。
我们把「说服」做成战斗：嘴硬值 = 血条，金句 = 伤害，AI 裁判当场判分。
想验证一件事——LLM 不只是聊天框，也能当有性格、有判定的游戏对手。
LifeHack 赛道命题「用 AI 解决生活小问题」：我们的解法是先把人气笑，再顺手把碗洗了。

## 四、怎么用（5 步）

1. 打开链接，看到嘴硬室友阿伟和他的 100 点嘴硬值（头部可切换卷王 / 主席两位 Boss）
2. 点弹药（🧠讲道理 / 🌚阴阳回去 / 🌀胡搅蛮缠），或输入框自己写一句骚话
3. 点「出招」，阿伟流式嘴硬回怼，AI 裁判实时判伤害扣血
4. 复读同一句会被裁判判低伤；试试💉试图开挂会被注入拦截反嘲讽；👁透视可看双 LLM 幕后判定（彩蛋）
5. 8 回合内打空血条 = 破防成功，慢镜头处刑演出后保存战绩卡发群挑衅朋友；失败也有「反被破防」卡

## 五、Qoder 制作过程

- **SDD 规格驱动**：specs/001-pofang-demo 与 specs/002-p1-presentation 下 requirements / design / tasks 三件套先行，
  Mock 引擎当天可玩，再按里程碑接真 LLM，每步验收写回规格
- **Qoder Sites 部署**：Vite+React 前端 + Deno 云函数 /functions/v1/app，一键发布公网，移动端适配
- **Qoder Cloud Agents 双 Agent**：演员（嘴硬人设流式回怼）∥ 裁判（JSON 判分）并行调用，
  SSE 逐字推给浏览器；演员 10s / 裁判 12s 预算实测调参；三 Boss 人设随回合下发、共享同一组 Agent
- **可靠性设计**：PAT 缺失 / 超时 / 坏 JSON 自动降级预置池 + 固定伤害表，游戏永不白屏；
  规则层提示注入拦截，0 伤害不耗回合
- **演出与透视**：破防慢镜头处刑演出（可跳过）；透视模式展示双 LLM 耗时 / 降级标记 / 裁判原始 JSON
- **战绩卡**：前端 Canvas 合成 720×920 街机风战报，含站点水印，长按保存即分享素材
- **实测数据**：M3 验收局 4 回合破防 32.6s；M4 线上卷王局 4 回合 21.1s，裁判真判 4/4（−34/−28/−35/−31 落锚点区间），演员 4/4 即兴无降级
